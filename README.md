# Student Management System

A web-based Student Management System built using React, FastAPI, and MySQL. It helps manage student records through a simple and user-friendly interface.

## Features

- Add new student records
- View all student records
- Edit existing student details
- Delete student records
- Search student records
- Input validation
- Success and error messages
- Department-based student IDs (CSE, ECE, EEE, IT)

## Technology Stack

**Frontend**
- React
- Vite
- JavaScript
- CSS

**Backend**
- Python
- FastAPI
- Pydantic

**Database**
- MySQL
